# 📋 תיקיית קונפיגורציה

> [!NOTE]
> סטטוס: `legacy-design-note`.
>
> המסמך מתאר שכבת הרחבה ניסיונית ואינו מקור חזון, מקור scope או תיעוד ארכיטקטורה קנוני. מקור ה־scope המוצע הוא [`docs/product/intended-use.md`](../../../docs/product/intended-use.md), שעדיין מסומן `draft-for-review`; הארכיטקטורה הנוכחית מתועדת ב־[`README.md`](../../../README.md).
>
> יש לאמת כל קובץ override מול קוד ה־bootstrap, נתיב ה־build וה־tracker לפני שמציגים אותו כנתמך. בפרט, קיום קובץ בתיקייה זו אינו מוכיח שהוא נארז או נטען ב־runtime.

תיקייה זו מכילה קבצי קונפיגורציה חיצוניים המאפשרים התאמה והרחבה של המערכת **ללא שינוי בקוד המקור**.

## מטרות

* התאמות ארגוניות או ניסיוניות
* שינוי התנהגות מערכתית
* תיעוד ניסויי של אפשרויות override, ללא שינוי ב־scope המוצר

## סדר עדיפות טעינה

1. `index.html` – Bootstrap עם `window.__INITIAL_FLOW_DATA__`
2. JSON ברירת מחדל מ-`src/protocols/`
3. קבצי קונפיגורציה מתיקייה זו
4. Runtime State

## קבצים אפשריים

* `feature-flags.json` – דגלים להפעלה/כיבוי פיצ'רים
* `flow-overrides.json` – עקיפת זרימות קיימות
* `ui-behavior.json` – התאמות UI
* `environment.json` – משתני סביבה

## כללים

* קונפיגורציה **משנה** התנהגות, לא מוחקת דאטא
* קונפיגורציה **גוברת** על ברירת מחדל
* אין לשמור PII או סודות בתיקייה זו
