# למידה ללא רשת — חוזה מימוש

## היקף

היכולת מיועדת לקריאה וללמידה בלבד. היא אינה כלי מבצעי, אינה מיועדת לקבלת החלטות או לטיפול בזמן אירוע חי, ואינה מחליפה הכשרה, פרוטוקול ארגוני עדכני או הנחיה של גורם מוסמך.

## תלות בחוזים קיימים

- משימה 54: צומת נכנס לחבילה רק כאשר כל המקורות שלו עוברים את `isApprovedForDisplay`, כולל `verified`, סמכות `confirmed`, שתי החלטות approval מזוהות וסקירה בתוקף.
- משימה 55: גבול השימוש הלימודי מוצג במנהל החבילה ובקורא הנפרד; אין טענת אישור קליני, משפטי או ארגוני.
- משימה 68: סביבת העריכה יכולה להכין revisions ולהעביר אותם בשערים, אך אינה מפרסמת. חבילת offline צורכת רק תוכן קנוני שמופיע ב־runtime provenance המאומת; טיוטות מקומיות אינן נכנסות לחבילה.

## ארכיטקטורה

1. האפליקציה הראשית בונה projection לקריאה בלבד מתוך הפרוטוקול ו־runtime provenance.
2. כל צומת ללא מקור, עם מקור `pending`, סמכות `unknown`, review חסר/פג או mismatch מושמט. אם לא נשאר אף צומת, ההתקנה נחסמת.
3. navigation actions מוסרות מהחבילה. הקורא מציג תוכן ומקורות בלבד.
4. החבילה נחתמת ב־SHA-256 ומכילה גרסת פרוטוקול, base SHA של העקיבות, תאריך יצירה ותוקף הסקירה המוקדם ביותר.
5. Service Worker מוריד shell נפרד של `offline-learning.html` ואת נכסיו בלבד. הוא אינו שומר `/api/*`, תגובות, auth, credentials, פרטי חשבון או מידע אישי.
6. עדכון נכתב ל־cache גרסאי חדש. רק לאחר שכל המשאבים והחבילה נכתבו, רשומת ה־active מוחלפת בפעולת `put` אחת. לאחר ההחלפה נמחקות גרסאות קודמות. כשל או ביטול מוחקים את ה־staging ומשאירים את הגרסה הפעילה הקודמת.
7. המשתמש יכול לבטל הורדה פעילה ולמחוק את כל חבילת הקריאה מהמכשיר.
8. הקורא בודק integrity ותוקף בכל פתיחה. חבילה פגומה או ישנה נחסמת ולא מוצגת.

## מצב התוכן בבסיס הנוכחי

נכון לבסיס `939403748341b5c220a189af9a504a30cd1445e5`, כל 205 הצמתים נכשלים סגור לצורך offline משום שהמקורות עדיין `pending` והסמכות `unknown`. לכן הממשק מציג `0 מאושרים, 205 הושמטו` ואינו יוצר חבילה. זו התנהגות בטוחה ומכוונת, לא השלמת review קליני.

## בדיקות

- projection מאושר סינתטי והסרת navigation actions.
- חסימה ב־`loading`, ‏`error` ו־`stale` של provenance.
- חסימה מלאה של dataset קנוני שבו 205/205 הצמתים אינם מאושרים.
- tamper detection ותוכן שפג תוקפו.
- commit אטומי של גרסה חדשה.
- כשל הורדה וחבילה חלקית משאירים את הגרסה הקודמת פעילה.
- ביטול הורדה ומחיקה יזומה.
- בדיקת דפדפן אמיתי: התקנת fixture סינתטי לא־רפואי, מעבר Chromium ל־offline מלא ורענון מוצלח של הקורא עם גרסה גלויה. לאחר הבדיקה ה־fixture נמחק.

הבדיקה הסינתטית מוכיחה את תשתית מצב הטיסה בלבד. היא אינה מוכיחה זמינות offline של התוכן הקליני הנוכחי, משום שתוכן זה טרם עבר את שערי האישור.
