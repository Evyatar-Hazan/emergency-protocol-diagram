# חוזה מדידה לימודי שומר פרטיות

סטטוס: טיוטת מימוש מקומית למשימה Jarvis #67. החוזה אינו מאשר איסוף חי, ספק analytics, dashboard או שינוי בפרודקשן.

## גבול המוצר

המדידה מיועדת לשיפור מוצר למידה בלבד. היא אינה מודדת טיפול, ביצוע קליני בשטח, מטופלים, כשירות מוסמכת או החלטה רפואית. אין להסיק ממנה התאמה קלינית או להשתמש בה להערכת מטפל יחיד.

## שאלות מוצר מותרות

1. כמה אירועי התחלת למידה נרשמים לכל חוויית למידה?
2. באילו עומקי זרימה ובאילו צמתים מאושרים נרשמות צפיות מצטברות?
3. מה היחס המצטבר בין אירועי התחלה להשלמה, ובאיזה טווח זמן גס הושלמה הזרימה?
4. אילו פריטי reference מאושרים נפתחים בתדירות מצטברת?

החוזה אינו תומך ב־unique users, מסע משתמש אישי, attribution, פרופיל לומד, cohort אישי או מעקב חוצה מכשירים.

## סכמת אירועים מינימלית

כל האירועים הם allowlist סגור. אין מעטפת כללית עם `properties` חופשיים.

| event | שדות מותרים בלבד | מטרה |
|---|---|---|
| `learning_started` | `schemaVersion`, `event`, `experience`, `contentVersion` | מונה התחלות לפי חוויה |
| `learning_step_viewed` | שדות משותפים + `nodeId`, `depthBucket`; `experience=guided_flow` | מונה צפיות מצטברות בצומת ובעומק |
| `learning_completed` | שדות משותפים + `elapsedBucket`; `experience=guided_flow` | מונה השלמות וטווח זמן גס |
| `reference_opened` | `schemaVersion`, `event`, `referenceType`, `contentVersion`, `contentId` | מונה פתיחות reference |

ערכי `nodeId` ו־`contentId` חייבים להופיע בקטלוג תוכן שנבנה מהגרסה הפעילה. לא מתקבל מזהה חופשי. `depthBucket` ו־`elapsedBucket` הם טווחים סגורים; אין מספר מדויק ואין timestamp בצד הלקוח. תאריך UTC יומי, אם יאושר איסוף בעתיד, ייגזר בצד האיסוף ולא ייכלל בגוף האירוע.

## שדות ותכנים אסורים

- מזהי משתמש, מטופל, session, cookie, מכשיר, חשבון Google או מזהה פרסומי — גם אם הם hashed או pseudonymous.
- שם, אימייל, טלפון, כתובת, תאריך לידה או כל PII אחר.
- טקסט חופשי, תגובות, הערות, חיפוש, URL, referrer או query string.
- סימפטומים, מדדים, אבחנה, תרופות, תיאור מקרה או כל מידע קליני אישי.
- IP בגוף האירוע, user-agent, fingerprint, מיקום, GPS או מאפייני מכשיר.
- timestamp מדויק, זמני לחיצה, sequence אישי או שדה שמאפשר לשחזר מסע של אדם.
- payload גנרי, metadata פתוח או שדה שלא מופיע במפורש בגרסה זו.

לוגי תשתית, אם יהיו, הם מאגר נפרד מחוזה analytics זה ודורשים מדיניות ואישור משלהם. אסור להעתיק מהם IP או מזהים למאגר המדידה.

## הסכמה ושליטה

- ברירת המחדל היא כבוי. אין שליחה לפני opt-in מפורש ובהיר למדידת מוצר לימודי.
- סירוב אינו פוגע בגישה לתוכן. אין backfill אחרי הסכמה.
- ביטול הסכמה עוצר יצירת אירועים ומוחק מיד buffer מקומי שלא נשלח.
- העדפת ההסכמה נשמרת מקומית בלבד וללא מזהה שרת. נוסח ההסכמה, מנגנון המחיקה והבסיס המשפטי דורשים אישור פרטיות לפני איסוף חי.
- אין telemetry לצורך בדיקת עצם ההסכמה; כך נמנע אירוע שמזהה את מי שסירב.

## Retention ומזעור

אם וכאשר יאושר backend עתידי:

- אירועים גולמיים: עד 7 ימים, למחיקה אוטומטית ובלתי הפיכה.
- אגרגטים יומיים ללא מזהים: עד 90 ימים, ואז מחיקה אוטומטית.
- אין גיבוי ארוך־טווח של raw events ואין export ל־data lake.
- קבוצה קטנה מ־10 אירועים ביום ובחתך נתון לא תוצג; היא תאוחד ל־`other` או תושמט.
- מאחר שאין מזהה אישי, לא ניתן לבצע lookup או מחיקה לפי משתמש. זו מגבלה מכוונת; יש להסביר אותה באישור הפרטיות.
- שינוי retention, הוספת dimension או קישור למאגר אחר מחייבים גרסת schema חדשה ואישור פרטיות/אבטחה.

## זרימת נתונים מאושרת עקרונית, לא ממומשת

1. UI בודק opt-in מקומי.
2. ה־UI יוצר רק אחד מארבעת האירועים.
3. validator דוחה שדות נוספים, מזהים, טקסט חופשי ומזהי תוכן שאינם בקטלוג.
4. collector עתידי, אם יאושר, מוסיף bucket יומי, צובר ומוחק raw בתוך 7 ימים.
5. dashboard עתידי יקרא אגרגטים בלבד ויחיל סף מינימום 10.

לא נבחר ספק, לא נוצר endpoint, לא בוצעה שליחה ולא הוגדר dashboard.

## תנאי מעבר לאיסוף חי

- אישור חוזה השימוש הלימודי והצגת scope עקבי.
- אישור פרטיות לנוסח ההסכמה, retention, מחיקה והפרדת לוגי תשתית.
- threat review ואישור אבטחה ל־collector ולמאגר.
- בדיקות integration שמוכיחות שאין cookies, מזהים, IP אפליקטיבי או payload חופשי.
- החלטה מפורשת על בעלות, גישה, incident handling ומחיקה.
- אישור נפרד לכל ספק, עלות, credential, הרשאה או deployment.

## בדיקות קבלה

- ארבעת האירועים התקינים עוברים עם קטלוג סינתטי בלבד.
- מזהי משתמש/מטופל/session/device נדחים.
- PII, תוכן קליני אישי, טקסט חופשי ושדות tracking נדחים.
- כל שדה לא מוכר נדחה גם אם שמו אינו ברשימת האיסור.
- מזהה תוכן שאינו בקטלוג וגרסה שאינה פעילה נדחים.
- אין בדיקה, fixture או snapshot המכילים נתוני מטופלים.
