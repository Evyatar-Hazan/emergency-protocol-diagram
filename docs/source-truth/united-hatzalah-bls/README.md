# מקור אמת לקורס BLS - איחוד הצלה

## מטרה

התיקייה הזו מרכזת שכבת `source of truth` מסודרת עבור חומרי הקורס מתוך תיקיית Google Drive בשם `איחוד הצלה`.

המטרה בשלב הזה:

1. לשמר את מבנה הקורס המקורי.
2. לקשר כל יחידת ידע לקובץ המקורי בדרייב.
3. להחזיק עותק טקסטואלי מסודר, לפני כל התאמה לתרשים הזרימה של האתר.
4. ליצור בסיס עבודה בטוח לאימות, תיקון והרחבת התוכן באתר.

## עקרונות עבודה

- תיקיית הדרייב היא מקור האמת הראשי.
- הקבצים כאן הם שכבת ארגון והנגשה, לא מקור חלופי.
- אין לבצע כאן "שכתוב קליני" בלי לציין זאת במפורש.
- כל מסמך חייב לכלול:
  - שם הקובץ המקורי
  - מזהה או קישור ל-Drive
  - תאריך שליפה
  - סטטוס עיבוד
- בשלב זה נשמרת עדיפות לנאמנות למקור על פני ניקיון ניסוחי.

- `modules/` - קבצי מקור מאורגנים לפי יחידות הקורס.

## סטטוס נוכחי

- אינדקס מלא של תיקיית הדרייב נבנה ומתועד ב־[course-inventory.md](./course-inventory.md).
- נוצרו 46 מסמכי מודול עבור יחידות הקורס והנוהל המשלים:
  - מבוא לקורס
  - מבוא להחייאה
  - החייאת מבוגר מטפל יחיד
  - החייאה בזוג ומכשירים
  - החייאת ילדים, תינוקות וחנק
  - אנמנזה וגישה לחולה
  - יתר יחידות הרפואה, הטראומה, המצבים המיוחדים והתפעול המפורטות באינדקס
- הקבצים המשלימים סווגו כמודול, reference או פריט שאינו מקור קליני ישיר; אין פריט מרכזי שמסומן כממתין לקליטה ראשונית.
- הקשר בין כל מודול לבין הזרימה מתועד ב־[source-to-flow-mapping.md](./source-to-flow-mapping.md), בסטטוסים `מכוסה`, `חלקי-טוב`, `משני` או `לא יעד זרימה`.
- קליטה ומיפוי אינם אישור קליני. פערי מקור, גרסה ואישור מנוהלים בנפרד ב־[project-tracker.md](../../tracking/project-tracker.md), ושערי `CONTENT-001`, `CLIN-001` ו־`CLIN-002` נשארים פתוחים עד שיוכחו תנאי הסגירה שלהם.

## תחזוקה ושימוש

לאחר השלמת הקליטה הראשונית, העבודה השוטפת היא:

1. לשמור את האינדקס והמיפוי מסונכרנים עם חומרי המקור ועם הזרימה.
2. לזהות ולתעד פערים בין מבנה הקורס לבין מבנה המוצר.
3. לאמת מקור, גרסה, גבול הכשרה ומשמעות קלינית באמצעות בעלי התפקיד המוסמכים.
4. לשמור סימון מפורש של תוכן ליבת BLS, תוכן reference ותוכן שאינו יעד לזרימה.

שכבת המקור הזו אינה מרחיבה את השימוש המיועד במוצר. מסמך ה־scope המוצע הוא [`docs/product/intended-use.md`](../../product/intended-use.md), שעדיין מסומן `draft-for-review`.
